Частые вопросы

Всё, что важно знать.

UrbanMove — настоящий сервис аренды?

Нет, это учебный прототип лендинга, созданный для демонстрации возможностей HTML, CSS, JavaScript и инструментов искусственного интеллекта.

Можно ли забронировать транспорт?

Пока нет. Интерфейс показывает концепцию продукта, но не подключён к реальному сервису аренды.

Есть ли мобильная версия?

Да. Страница адаптируется к ширине экрана, а для мобильных устройств предусмотрено компактное меню.

Куда отправляются данные из формы?

Никуда: форма работает в демонстрационном режиме и не передаёт данные на сервер.
